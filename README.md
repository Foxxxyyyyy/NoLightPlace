# NoLightPlace

**NoLightPlace** — мод для Fabric (Minecraft 1.20.1–1.21.11), который по нажатию клавиши блокирует установку источников света из левой руки.

## Зачем этот мод
В игре я столкнулся с неприятной мелочью: когда ешь или занимаешься другими делами, случайно раставляешь факелы и другие источники света из левой руки. Я начал искать готовое решение и не нашёл — никто такого не сделал. Поэтому написал мод сам и выложил его в открытый доступ, чтобы им мог воспользоваться любой, кто наткнулся на ту же проблему.

## Как работает
- По нажатию отдельной клавиши (назначение можно посмотреть и поменять в меню «Управление») мод блокирует установку источников света — факелов, фонарей и подобных — из левой (второй) руки.
- На основную руку мод не влияет: она работает как обычно.

## Установка
1. Установите Fabric Loader для Minecraft 1.20.1–1.21.11.
2. Скачайте версию мода под свою версию игры: [Modrinth](https://modrinth.com/mod/no-light-place), [CurseForge](https://www.curseforge.com/minecraft/mc-mods/no-light-place) или раздел [Releases](../../releases).
3. Положите `.jar` в папку `mods`.
4. Запустите игру.

## Сборка из исходников
```bash
git clone https://github.com/Foxxyxyxyxy/NoLightPlace.git
cd NoLightPlace
./gradlew build
```
